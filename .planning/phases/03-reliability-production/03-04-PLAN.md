  <action>
    1. Touch Target Hardening (Minimum 44x44px CSS bounding box):
       - `activities.$id.tsx`:
         - Step checkboxes: Ensure the clickable container has `min-h-[44px] min-w-[44px]` with adequate touch padding.
         - Outcome buttons (`"Tried — Helped"`, `"Tried — Needs Support"`, `"Not Tried"`): Ensure `min-h-[48px]` and responsive wrapping on small screens (`grid-cols-1 sm:grid-cols-3` if screen width < 360px).
         - Child dropdown selector: Ensure minimum touch height of 48px with clear chevron tap area.
       - `children.$id.tsx`:
         - Action buttons (`"Sync now"`, `"Record Observation"`): Enforce `min-h-[44px]`.
    2. Color Contrast & Outdoor Readability:
       - Verify badge text colors against backgrounds:
         - Teal soft badge: text-teal-800 on bg-teal-100 (contrast > 4.5:1).
         - Sun/Amber badge: text-amber-900 on bg-amber-100 (contrast > 4.5:1).
         - Coral/Alert badge: text-coral-800 on bg-coral-100 (contrast > 4.5:1).
    3. Keyboard & Screen Reader Accessibility:
       - Step items: add `role="checkbox"`, `aria-checked={isDone}`, `tabIndex={0}`, and `onKeyDown` handlers for Space and Enter keys.
       - Outcome buttons: add `aria-pressed={isCurrentSelection}`.
       - Visible focus indicators: add `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2`.
    4. Viewport Overflow Verification:
       - Test CSS classes for `overflow-x: hidden`, flexible wrapping (`flex-wrap`), and responsive grid scaling across 320px, 375px, 768px, and 1024px.
  </action>
  <verify>Run `npm run build` and `npx tsc --noEmit`. Verify no layout breaks across responsive breakpoints.</verify>
