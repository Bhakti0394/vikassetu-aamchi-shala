<objective>
Implement a persistent IndexedDB storage adapter for offline activity trial logs in `src/lib/activityLogs.ts`, replacing volatile in-memory-only retention while handling storage unavailability gracefully and honestly.

Purpose: Guarantee that preschool teachers in rural/intermittent connectivity areas do not lose recorded trial logs when refreshing the page, closing browser tabs, or experiencing mobile browser memory eviction.
Output: Hardened `src/lib/activityLogs.ts` and comprehensive automated test suite in `src/lib/activityLogs.test.ts`.
</objective>

    Update `src/lib/activityLogs.ts`:
    1. Define storage adapter interface and types:
       ```ts
       export type StorageEngineType = "indexeddb" | "memory_fallback";

       export type StorageStatus = {
         engine: StorageEngineType;
         isPersistent: boolean;
         warning?: string;
       };
       ```
    2. Implement lightweight, native IndexedDB store (Database: `VikasSetuOfflineDB`, Store: `pendingTrials` with keyPath `queueId` and index on `childId`):
       - `openDatabase()`: Opens/upgrades IndexedDB with proper version handling.
       - `saveToStorage(item: QueuedActivityTrial)`: Persists item to IndexedDB.
       - `loadFromStorage()`: Loads all queued items asynchronously on initialization.
       - `removeFromStorage(queueId: string)`: Deletes synced items.
       - `updateInStorage(item: QueuedActivityTrial)`: Updates status/error for failed items.
    3. Storage failure & honesty behavior:
       - If IndexedDB is blocked (e.g. private mode, quota exceeded, disabled in environment), gracefully transition to in-memory fallback.
       - DO NOT silently claim persistence is guaranteed: expose `getStorageStatus(): StorageStatus`.
       - When in fallback mode, set `isPersistent: false` and include explicit warning (`"Browser storage unavailable; records remain session-only until synced"`).
    4. Maintain backward-compatible API contracts:
       - `queuePendingTrial(payload, error)`: Appends to queue and writes to storage.
       - `getPendingTrials(childId?)`: Returns in-memory cache synchronized with storage.
       - `clearPendingTrials()`: Clears both cache and storage store.
       - `initOfflineQueue()`: Hydrates queue from IndexedDB on initial application mount.
    5. Unit and Integration Tests in `src/lib/activityLogs.test.ts`:
       - Test IndexedDB storage read/write/delete.
       - Test reload simulation (re-initializing queue from storage).
       - Test quota/permission failure graceful fallback with honest `isPersistent: false`.
  </action>
